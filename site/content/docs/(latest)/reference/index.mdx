title: Entry points
description: What each entry point exports, and the reference page that lists it.

Effetch Query is one package with five entry points: the package root
and four subpaths. Import only the ones you use: the core has no framework
in it, and each framework entry needs only its own peer dependencies.

Each reference page lists every export of its entry point or namespace,
grouped by the guide that covers it, with its docs. Your editor's hover and
"Go to Definition" show the same docs, with an example.

The package has the following entry points:

| Entry point                                      | What it exports                                                                                              | Reference                                                     |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| `@monarcode/effetch-query`                       | The core, with no framework in it: six namespaces, `Register` and `QueryFailure`.                            | [`@monarcode/effetch-query`](/docs/reference/core)            |
| `@monarcode/effetch-query/react`                 | The provider, the hooks and the boundaries.                                                                  | [`@monarcode/effetch-query/react`](/docs/reference/react)     |
| `@monarcode/effetch-query/effetch`               | `fromClient`, which turns Effetch endpoints into queries and mutations, its types, and `EndpointQueryError`. | [`@monarcode/effetch-query/effetch`](/docs/reference/effetch) |
| `@monarcode/effetch-query/react-native`          | `reactNativeSignals`, which builds a client's signals from React Native modules you pass in.                 | [`…/react-native`](/docs/reference/react-native)              |
| `@monarcode/effetch-query/react/tanstack-router` | `connectQueryClient`, which connects a client to TanStack Router and TanStack Start.                         | [`…/react/tanstack-router`](/docs/reference/tanstack-router)  |

The core entry point's six namespaces, `Query`, `InfiniteQuery`, `Mutation`,
`Entity`, `QueryClient` and `Signals`, each have a page, listed on
[`@monarcode/effetch-query`](/docs/reference/core).

For what 0.1 doesn't do, see [Limitations](/docs/reference/limitations).
