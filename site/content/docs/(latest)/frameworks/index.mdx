---
title: Frameworks
description: Use Effetch Query with TanStack Router and Start, Next.js or React Router.
---

Each framework page builds on [Server rendering](/docs/server-rendering):
the examples use `todos` from [Getting started](/docs/getting-started) and
`TodoList` from [Send the cache](/docs/server-rendering). Pick yours:

- [TanStack Router and Start](/docs/frameworks/tanstack-start): the
  `@monarcode/effetch-query/react/tanstack-router` integration,
  `connectQueryClient`, sends the cache with the page and loads it before
  React hydrates.
- [Next.js](/docs/frameworks/nextjs): the App Router, with the core and
  `./react` only.
- [React Router](/docs/frameworks/react-router): framework mode, with the
  core and `./react` only.

Without a framework, [Send the cache](/docs/server-rendering) and [Load the
cache in the browser](/docs/server-rendering/hydrate) show the whole
round trip with any React server renderer.
